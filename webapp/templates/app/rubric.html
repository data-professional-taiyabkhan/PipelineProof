The recommendation

A report says Review findings before advancing if any finding is critical or high, the gap is above 0.10, or the overall score is below 75. Otherwise it says No blocking findings. If the pipeline could not run, it says Could not be scored and explains why.

Either way, the recommendation is advice. A named reviewer confirms or overrides it with a reason, and that decision is what counts.

Signals from reading the code (patterns found without running it) are shown to the reviewer but never change a score.
